# Ejercicio5Cliente

Aplicacion web del gestor de proyectos, construida con Java y Spring Boot.

## Requisitos

- JDK 17 o compatible.
- Maven 3.9.9, incluido mediante Maven Wrapper.

## Ejecutar

En Windows, desde esta carpeta:

```powershell
.\mvnw.cmd spring-boot:run
```

La version de Java objetivo se configura como `17` en `pom.xml`.
